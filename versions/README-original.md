# Le Défi Boréal — projet maître

## Version de référence
- `current/index.html` : V2 conservée sans modification.
- `versions/v1-reference.html` : sauvegarde V1.
- `versions/v2-reference.html` : sauvegarde V2.

## Règles de maintenance
1. Ne jamais réécrire le jeu complet pour une correction ponctuelle.
2. Partir de `current/index.html` et ne changer que les fonctionnalités demandées.
3. Enregistrer une copie datée dans `versions/` avant chaque modification.
4. Vérifier la syntaxe JS et les références DOM; tester sur navigateur mobile avant toute affirmation de validation mobile.
5. Fournir le fichier HTML complet et un ZIP déployable.
6. Préserver menus, scores, titres, mécanique et palette sauf demande explicite.
7. Les assets de pixel art pourront être isolés dans `assets/` dans une version future.

Cette archive est un point de départ portable. Conservez-la et joignez-la à une nouvelle conversation pour garantir la continuité du code.
