    À garder sous la mainLe rabais en 3 étapes+
    1. 1

      Vérifier et prendre en charge

      Vérifiez le nom, la valeur et la date limite. Cliquez sur « PRENDRE EN CHARGE », puis confirmez. Attendez que la fiche affiche « Pris en charge » à votre nom.

    2. 2

      Appliquer le rabais sur la facture

      Après la confirmation, appliquez manuellement une seule fois le rabais dans Lightspeed, exclusivement sur les aliments admissibles. Aucun rabais direct ou indirect sur l’alcool. Si les aliments valent moins que le bon, appliquez seulement leur valeur et le reliquat est perdu. Une facture uniquement alcoolisée est refusée.

    3. 3

      Confirmer le rabais appliqué

      Cochez « Le rabais a été appliqué sur la facture », puis confirmez. Seul l’employé ayant pris en charge le code peut terminer.

    En cas de doute, n’appliquez pas un deuxième rabais. Un code « Pris en charge » est verrouillé. L’employé concerné doit vérifier la facture avant de reprendre. Si une erreur apparaît après confirmation, actualisez d’abord le registre.

    Le code est utilisable dans les 30 jours suivant son attribution. Chaque employé utilise son compte individuel, puis se déconnecte sur un appareil partagé.
